# DealerDesk

DealerDesk is a web‑based platform that automates data entry for car dealerships and provides real‑time inventory management.

- **Frontend** – React 18 + TypeScript + TailwindCSS
- **Backend** – Node.js (Express) + TypeScript, PostgreSQL, Redis
- **Integration** – Connector service to push vehicle data to the dealer's DMS

This repository contains a minimal monorepo scaffold with separate `frontend` and `backend` packages.
